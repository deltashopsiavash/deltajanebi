# DeltaJanebi

فروشگاه مستقل لوازم جانبی موبایل با رابط RTL، ثبت‌نام ایمیلی، بازیابی رمز، سبد خرید، سفارش/رسید، پیگیری سفارش، مدیریت تلگرامی و محصولات همگام‌شونده از منبع همکاری.

> این پروژه کپی سورس یا دارایی‌های اختصاصی `hamrahedovom.ir` نیست. رابط فروشگاهی مستقل و مشابه از نظر ساختار تجربه خرید ساخته شده است. همگام‌سازی منبع فقط برای دامنه‌های مجاز تنظیم‌شده در `.env` انجام می‌شود و باید مطابق مجوز/شرایط همکاری شما با منبع باشد.

## محصول عادی و محصول خاص

- **عادی:** نام، قیمت، موجودی و تصویر را از ربات ثبت می‌کنید.
- **خاص/همگام:** در ربات لینک محصول منبع را می‌فرستید. سیستم نام، توضیح، عکس‌ها، ویژگی‌ها، قیمت و موجودی را استخراج می‌کند؛ سپس از شما markup می‌خواهد:
  - `20%` یعنی ۲۰٪ بالاتر از قیمت منبع.
  - `20000` یعنی ۲۰٬۰۰۰ تومان بالاتر از قیمت منبع.
- سرویس `sync` هر `SOURCE_SYNC_INTERVAL` ثانیه (پیش‌فرض ۱۸۰۰ = ۳۰ دقیقه) محصولات خاص را دوباره بررسی می‌کند و قیمت/موجودی/اطلاعات را به‌روز می‌کند.

پارسر ابتدا JSON-LD Product و OpenGraph را می‌خواند و بعد fallbackهای HTML دارد. اگر سایت منبع HTML خود را تغییر دهد و داده ساختاریافته نداشته باشد، ممکن است selector اختصاصی لازم شود؛ خطا داخل `Product.sync_error` ثبت می‌شود.

## نصب یک‌خطی روی Ubuntu/Debian خام

```bash
curl -fsSL https://raw.githubusercontent.com/deltashopsiavash/deltajanebi/main/install.sh | sudo bash
```

اسکریپت دامنه، توکن ربات و Telegram Admin ID را می‌پرسد، Docker را نصب می‌کند، `.env` می‌سازد، PostgreSQL/Web/Bot/Sync/Caddy را بالا می‌آورد و HTTPS را برای دامنه فعال می‌کند.

DNS دامنه باید قبل از نصب به IP سرور اشاره کند.

## آپدیت بدون خام‌کردن سرور

بعد از نصب فقط:

```bash
sudo deltajanebi-update
```

یا داخل پوشه پروژه:

```bash
sudo bash /opt/deltajanebi/update.sh
```

Docker فقط سرویس‌های پروژه را rebuild/restart می‌کند؛ دیتابیس و media روی volume پایدار هستند.

## تنظیمات مهم `.env`

- `TELEGRAM_BOT_TOKEN`: توکن BotFather
- `TELEGRAM_ADMIN_IDS`: آیدی عددی مدیرها با کاما
- `SOURCE_ALLOWED_HOSTS`: فقط دامنه‌های مجاز برای جلوگیری از SSRF
- `SOURCE_SYNC_INTERVAL=1800`: فاصله sync
- SMTP: برای بازیابی واقعی رمز با ایمیل

## پنل ربات

`/start`:
- افزودن محصول خاص
- افزودن محصول عادی
- سفارش‌های اخیر و تغییر وضعیت به آماده‌سازی/ارسال/لغو
- Sync فوری محصولات خاص
- تغییر هزینه ارسال
- تغییر URL لوگو

## مدیریت Django

برای ساخت superuser:

```bash
cd /opt/deltajanebi
sudo docker compose exec web python manage.py createsuperuser
```

پنل: `/admin/`

## نکات تکمیل قبل از فروش واقعی

1. شماره کارت/نام صاحب کارت را از admin یا دیتابیس `SiteSetting` تنظیم کنید.
2. SMTP واقعی را برای بازیابی رمز وارد کنید.
3. درگاه بانکی نیاز به مرچنت/کلید سرویس‌دهنده شما دارد و عمداً بدون credential داخل سورس hard-code نشده است.
4. اولین محصول خاص را در ربات تست کنید. اگر سایت منبع برای محصول موردنظر داده ساختاریافته متفاوتی برگرداند، `sync_error` مشخص می‌کند کدام parser باید اختصاصی‌تر شود.
